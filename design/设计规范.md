# 云器 ERP · 电器批发零售管理系统 — 界面设计规范

> 设计风格：**现代简约 · 蓝色商务** ｜ 设计者：UI Designer
> 交付物：`design/index.html`（可点击高保真原型）+ `assets/style.css`（设计令牌与组件）+ `assets/app.js`（原型交互）

---

## 一、设计目标与用户习惯

针对「电器批发 + 零售」混合业态，界面围绕三类核心角色设计：

| 角色 | 核心诉求 | 对应界面重点 |
| --- | --- | --- |
| **店长 / 老板** | 一眼看清经营状况 | 工作台 KPI、报表分析、应收账款催收 |
| **收银 / 导购** | 极快开单、少点击 | 销售开单三栏式、扫码枪、快捷键 |
| **仓管 / 财务** | 准确、可追溯 | 库存预警、采购入库、收付款对账、操作日志 |

**符合用户习惯的关键决策：**
1. **左侧固定模块导航 + 顶部全局搜索**：ERP 用户习惯「导航找功能、搜索找单据」，全模块常驻可见，减少记忆负担。
2. **销售开单采用「分类 / 商品 / 购物车+结算」三栏布局**：符合收银台心智模型，左手选品、右手结算，单屏完成开单。
3. **多价格体系（批发价 / 零售价 / 会员价）与多单位（台 / 箱 / 件）**：电器行业批发场景刚需，商品档案与开单均体现。
4. **库存预警在多处透传**：工作台红点、库存页、商品列表同步提示，符合「缺货即补」的操作直觉。
5. **状态用颜色 + 文字双重表达**（如「欠款=红」「部分收款=橙」），避免色盲误读，兼顾无障碍。

## 二、设计基础（Design Tokens）

### 2.1 色彩系统
- **品牌主色（专业蓝）**：`#2D5BE3`（主）、`#1E47C0`（hover）、`#EEF3FE`（浅底）
- **商务强调色（暖橙）**：`#FF7A33`，用于营收、促销、主行动按钮，与蓝色形成「理性 + 活力」对比
- **语义色**：成功 `#16A34A` ｜ 警告 `#D9870A` ｜ 危险 `#DC2626` ｜ 信息 `#2D5BE3`
- **中性灰阶（冷调）**：文字 `#0F1B2D / #2A3645 / #5B6675`，边框 `#E8ECF2`，背景 `#F4F6FB`，卡片 `#FFFFFF`
- **对比度**：正文/背景 ≈ 14:1，次要文字 ≈ 5.2:1，均满足 **WCAG AA**（正文 4.5:1）

### 2.2 字体与字号
- 字体栈：`"PingFang SC", "Microsoft YaHei", "Source Han Sans SC", Inter, system-ui`
- 数字专用：`DIN Alternate / SF Pro Display`（等宽数字，便于对账阅读）
- 字号阶梯：`12 / 13 / 14 / 15 / 16 / 18 / 20 / 24 / 30px`
- 字重：`400 / 500 / 600 / 700 / 800`

### 2.3 间距（8pt 体系）
`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48px`，保证视觉节奏统一。

### 2.4 圆角与阴影
- 圆角：`6 / 10 / 14 / 20px`（卡片 14、按钮 10、胶囊 999）
- 阴影：克制轻量（`sh-1` 微投影 → `sh-3` 弹窗重投影），强调层级而非装饰。

## 五、响应式策略

- **桌面（≥1180px）**：完整三栏开单、双列图表，工作流全部呈现。
- **平板（860–1180px）**：开单结算面板转为整宽置底；KPI 转 2 列。
- **移动（≤860px）**：侧栏变为抽屉（汉堡按钮 + 遮罩）；搜索隐藏；网格单列；满足仓管 PDA / 手机查单场景。
- **触控目标**：按钮、步进器、导航项均 ≥ 38–44px，符合移动端最小点击区。

---

## 六、无障碍（WCAG AA）

- 颜色对比度达标，状态均含文字/图标，不只靠颜色。
- 全局 `:focus-visible` 蓝色描边，键盘可完整操作导航与开单。
- 语义化标签（`<nav> <main> <section> <table>`）+ 图标 `aria-label`。
- 支持 `prefers-reduced-motion`（过渡时长克制，可扩展）。

## 七、可继续深化的方向

1. **深色模式**：增加 `[data-theme="dark"]` 令牌（已在令牌体系预留结构）。
2. **角色视图**：按店长 / 收银 / 仓管 / 财务定制首页与权限可见性。
3. **真实图表库**：接入 ECharts / AntV 替换内联 SVG，支持下钻与导出。
4. **设计交付物**：导出 Figma 组件库、标注稿与切图规范，供研发对接。
5. **多门店 / 多仓**：在导航与筛选器加入门店、仓库维度切换。
