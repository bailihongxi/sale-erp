# 家电批发进销存 ERP（纯前端 · 本地优先）

一个面向**家电批发 + 零售**的进销存管理软件（ERP）。纯前端、零后端、零账号登录，
所有业务数据保存在**浏览器本地**（localStorage），刷新 / 关闭 / 重启电脑都不丢失。
可一键部署到 **GitHub Pages** 联网访问，手机浏览器打开即可使用（以查看数据为主）。

> ⚠️ **只用一种方式打开本应用。** `双击 index.html`（file://）、`http://localhost:8080`、GitHub Pages 域名是**三个互相独立的存储位置**，数据互不相通。换一种打开方式就会看到另一份（可能是空的）数据——这不是 bug，而是浏览器安全隔离。固定用其中一种方式，需要迁移时请用「数据管理 → 导出 / 导入备份」。

## 功能模块（v1 全部可用）

| 模块 | 能干什么 |
|---|---|
| 工作台 | 今日营收 / 订单 / 库存预警 / 应收看板，近 7 天销售趋势、热销榜 |
| 商品管理 | 商品档案（**品牌 / 型号 / 类型** / 单位 / 批发价 / 零售价 / 库存 / 低库存阈值），新增编辑删除、搜索、按类型筛选、批量导入、批量操作、重名检测与合并 |
| 销售开单 | 选客户 → 选商品（搜索/类型筛选）→ 多数量多单价 → 优惠 → 收款方式（现金/微信/支付宝/银行/**欠款**）→ 生成销售单并出库 |
| 销售管理 | 销售单列表、详情、按单据收款冲抵欠款 |
| 采购管理 | 新建进货单（供应商 / 日期 / 搜索添加商品 / 可编辑数量单价 / 优惠结算）→ 入库并增加库存，支持欠款 |
| 库存管理 | 实时库存、低库存预警、出入库流水、库存调整 |
| 报表分析 | 累计销售额、估算毛利、应收 / 应付、近 7 天趋势、商品销量 TOP、客户销售排行 |
| 财务管理 | 应收（客户欠款）/ 应付（供应商未付）/ 收付款流水，一键收 / 付款 |
| 系统设置 | 店铺名称、默认低库存阈值、清空重置数据 |
| 数据管理 | **导出备份 / 导入备份**（JSON）、存储信息 |

## 在 Mac 本地运行（最推荐）

方式一：直接双击 `index.html` 用浏览器打开即可使用（Chrome / Safari / Edge 均支持本地存储）。
方式二（更稳定，推荐）：在终端进入本目录启动一个本地静态服务：

```bash
cd /path/to/SaleSystem
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

> 数据只存在**当前这台 Mac 的这个浏览器**里。换浏览器 / 清缓存 / 换电脑都不会带走，
> 请用「数据管理 → 导出备份」定期备份。

## 开发 & 测试（可选）

仓库自带零依赖的 npm 脚本（需 Node 环境）：

```bash
npm run serve    # 启动本地静态服务 http://localhost:8080
npm run check    # 语法门禁（node --check assets/*.js）
npm test         # 跑 318 项自动化断言（数据层 + 界面层，jsdom）
```

> 这些脚本仅用于本地开发与回归验证；最终产品是纯静态文件，双击 `index.html` 即可用，无需 Node。

## 部署到 GitHub Pages（联网 + 手机访问）

本仓库已内置 GitHub Actions 工作流（`.github/workflows/deploy.yml`），推送即自动发布：

1. 在 GitHub 新建一个**公开**仓库（如 `appliance-erp`）。
2. 本地已 `git init` 并提交，绑定远程并推送 `main` 分支：
   ```bash
   git remote add origin https://github.com/你的用户名/appliance-erp.git
   git branch -M main
   git push -u origin main
   ```
3. 仓库 → Settings → Pages → Source 选择 **GitHub Actions**。
4. 推送后会自动部署，几分钟后得到 `https://你的用户名.github.io/appliance-erp/` 网址。
5. 手机用浏览器打开该网址即可使用（手机端以查看数据为主，底部有「工作台/商品/开单/我的」）。

> 本仓库已发布的演示站点：`https://bailihongxi.github.io/sale-erp/`（数据保存在你自己的浏览器本地，与他人互不相通）。

> 说明：Mac 与手机是**两套独立数据、互不同步**。想把 Mac 的数据搬到手机，
> 在 Mac 上「导出备份」下载 JSON，再到手机「导入备份」即可。

## 技术说明

- 纯静态：`index.html` + `assets/style.css` + `assets/db.js` + `assets/app.js`，**无构建步骤、无依赖**。
- 数据层 `db.js`：localStorage 持久化 + 首次种子数据 + 通用 CRUD + 聚合查询（看板 / 预警 / 排行 / 应收应付）。
- 哈希路由，响应式布局：桌面侧边栏，手机底部标签栏。
- `design/` 目录为早期高保真设计稿（参考用，非运行必需）。
