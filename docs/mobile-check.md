## 三、已知限制与说明

1. **数据隔离是设计行为**：`双击 index.html`（file://）、`http://localhost:8080`、GitHub Pages 域名三者是互相独立的存储位置，数据互不相通。这不是缺陷，已通过顶栏「📍 数据位置」徽标提示用户，并在 README 顶部加粗警告。
2. **滚动表格的实现取舍**：手机端 `.table` 采用 `display:block; overflow-x:auto` 方案，宽表在卡片内横向滚动而非撑破页面。窄表（列少）仍铺满宽度（`min-width:100%`）。
3. **v1 移动端定位为「以查看为主」**：开单、导入等写操作已可用，但真机触摸手感、输入法适配、iOS 文件选取等需人工走查，建议 v1.1 后由实际使用反馈驱动 v1.2 优化（见 DEV_PLAN §5 Backlog：PWA 离线、键盘流开单等）。
