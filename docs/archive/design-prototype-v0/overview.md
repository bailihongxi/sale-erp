## 核心设计决策（贴合用户习惯）
- 左侧常驻模块导航 + 顶部全局搜索，符合 ERP「导航找功能、搜索找单据」习惯。
- 销售开单三栏式（分类 / 商品 / 购物车+结算），单屏完成收银与批发开单，支持扫码枪。
- 多价格体系（批发/零售/会员）与多单位（台/箱/件），适配电器批发零售混合业态。
- 库存预警在多页面透传（红点 + 列表 + 工作台待办）。
- 状态用「颜色 + 文字」双重表达，满足 WCAG AA 对比度与色盲可读。

## 下一步建议
